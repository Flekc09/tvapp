# Component State Matrix — TV App

**Status:** Approved by owner 2026-09-23 · Playbook C.3 · Gate S passed 2026-09-23
**Inputs:** `docs/ui/screens-and-flows.md` (§3 screens, §4 components), `docs/ui/design-tokens.md`.
**Rules of this matrix:** every cell is filled; "same as default" is a decision, a blank is not. Names in backticks are tokens. There is no pointer on a TV, so **Hover is "same as default" for every component** (brief, Playbook adaptations) and is kept as a column only so Gate S can check it. **Active** means OK is held down on the focused element (the pressed state, shown within `t-immediate`). **Focus-visible** is the state that matters: every interactive component gets `focus-border` + `focus-tint` plus either `focus-scale` (compact targets) or `focus-grow` (wide rows), within `t-fast`. Below, "scale + border + tint" on a row means grow + ring + tint.

## 3. Cross-cutting rules

- **One focus, always visible.** Exactly one element has focus on any surface, and it is restored by key when the list updates (token sheet §6). An overlay opens with focus on the most likely target: Channels on the current channel's row (or the first row), Settings on the first row, the card on Next channel, dialogs on their field.
- **Acknowledge within a frame.** Every OK press changes something on screen within `t-immediate`: the pressed tint, a filled PIN ring, a banner. The one deliberate exception was D4, now resolved by showing the banner.
- **Errors name the fix, keep the data.** Field errors quote what is wrong and preserve the entered value; dialog errors keep the dialog open; the tune error is the card, never a spinner.
- **Nothing is only colour.** Selected has a bar and an accent label; status has a shape and a word; on/off has a word; focus has scale and a ring.
- **Blacklist check (Playbook C.6):** confirmshaming, fake scarcity, drip pricing, sneak-into-basket, roach motel, forced continuity, trick wording, nagging, disguised ads, pre-selected extras — checked line by line against every component above: **no matches**. The one repeat prompt in the app, the poor-signal prompt, is rate-limited to once per 10 minutes per channel and never repeats after being dismissed within that window.
