# TV App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Android TV / Google TV app that downloads the catalog produced by the catalog job, turns on to a picture, tunes any channel in under two seconds, and fails over between duplicate feeds without the viewer touching the remote.

**Architecture:** Single-activity Kotlin app. A Room database holds the imported catalog plus local state. A `PlayerController` owns one ExoPlayer, the stream queue, failover, tune budget and measurement. Compose for TV renders one root player surface with overlays (Channels, Browse, Search, Favorites, Settings) drawn over the still-playing video. Every piece of logic that can be unit-tested on the JVM (queue ordering, demotion, tune budget, broken-here, import-id flip, M3U and catalog parsing) lives in plain Kotlin classes with injected clocks and no Android imports.

**Tech Stack:** Kotlin 2.x, Android Gradle Plugin 8.x, minSdk 28 (Android 9, the floor for current Google TV sticks), Jetpack Compose with `androidx.tv:tv-material`, Media3 ExoPlayer with `media3-exoplayer-hls`, `media3-exoplayer-dash`, `media3-datasource-okhttp`, Room with KSP, WorkManager, OkHttp, Coil 3, Gson streaming `JsonReader` for the catalog import, JUnit 4 + kotlinx-coroutines-test for JVM tests, AndroidX test + a local `MockWebServer` for instrumented tests.

**Spec:** `docs/superpowers/specs/2026-09-22-tv-app-design.md`, sections 1, 3.2, 3.3, 5, 6, 7, 8. The catalog file format is section 4.4 and is produced by `docs/superpowers/plans/2026-09-22-catalog-job.md`.

## Global Constraints

- User agent sent by every request: `TVApp/1.0 (Android TV; Media3)`. Must match the catalog job's `DEFAULT_UA` exactly.
- Default catalog base URL: `https://<owner>.github.io/<repo>` — the executor takes the real value from the catalog job's README after the owner has set it up. Until then the placeholder stays as a `BuildConfig` field and the Advanced setting overrides it.
- Cleartext HTTP allowed app-wide via `network_security_config.xml`; cross-protocol redirects allowed on the OkHttp data source. HTTPS validated normally, no self-signed exceptions.
- Manifest: `LEANBACK_LAUNCHER` intent category, `android.software.leanback` required, `android.hardware.touchscreen` not required, `android:banner` 320x180, `android:largeHeap="true"`.
- Buffer: `bufferForPlaybackMs = 1000`, `minBufferMs = 15000`, `maxBufferMs = 30000`, `backBufferDurationMs = 0`.
- Tune budget 10 s total; first-frame cutoff 4 s per stream with alternatives remaining, remaining budget otherwise. Demotion lasts 1 hour of `elapsedRealtime`. Broken-here requires 3 failed attempts across 3 distinct calendar days.
- Every list hides `adult = 1`, `hasUp = 0`, and `broken_here` channels unless the matching setting is on. Nothing on screen says HLS, TS, DASH, unverified, unsorted, demoted, or a stream count.
- Every timestamp used for expiry is `SystemClock.elapsedRealtime()`, injected as a `Clock` interface so tests can fake it. Calendar days for broken-here use `LocalDate` from an injected `DateProvider`.
- Commit after every task. Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Version catalog in `gradle/libs.versions.toml`. The executor verifies each library's current stable version on Maven Central before pinning; the numbers in Task 1 are the floor, not the ceiling.

## Review Focus

Inputs the spec implies but a first implementation is likely to break on. Each has a pinned test in the task named.

1. **Catalog import interrupted by standby halfway through.** On next launch, rows with the partial `import_id` must be deleted and the old catalog must still be active. Test in Task 4.
2. **A channel whose every stream is demoted, or a channel with exactly one stream.** The queue must still try something, and the single-stream cutoff must be the full remaining budget, not 4 s. Test in Task 6.
3. **The viewer holds Channel Down through ten channels.** Only the final channel tunes; abandoned tunes record no failures; the banner shows every intermediate channel. Test in Task 7 (debounce) and Task 11 (banner).
4. **An M3U line with `tvg-logo` containing a comma inside quotes, and `#EXTVLCOPT:http-user-agent=` lines.** The parser must not split attribute values on commas. Test in Task 5.
5. **Digits pressed with fewer favorites than the number.** Pressing 7 with 3 favorites must do nothing visible, not crash or tune channel 0. Test in Task 11.

```kotlin
package com.tvapp.core

import android.os.SystemClock
import java.time.LocalDate

interface Clock { fun elapsedMs(): Long }
interface DateProvider { fun today(): LocalDate }

class SystemClockImpl : Clock { override fun elapsedMs() = SystemClock.elapsedRealtime() }
class SystemDateProvider : DateProvider { override fun today(): LocalDate = LocalDate.now() }

class FakeClock(var now: Long = 0L) : Clock {
    override fun elapsedMs() = now
    fun advance(ms: Long) { now += ms }
}
class FakeDateProvider(var date: LocalDate = LocalDate.of(2026, 9, 22)) : DateProvider {
    override fun today() = date
    fun nextDay() { date = date.plusDays(1) }
}
```

```kotlin
import androidx.room.Dao
import androidx.room.Insert

@Dao
interface CatalogDao {

    @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun insertCategories(rows: List<CategoryEntity>)
```

```kotlin
package com.tvapp.data.catalog

import com.google.gson.stream.JsonReader
import com.google.gson.stream.JsonToken
import com.tvapp.data.db.CategoryEntity
import com.tvapp.data.db.ChannelEntity
import com.tvapp.data.db.CountryEntity
import com.tvapp.data.db.SOURCE_IPTV
import com.tvapp.data.db.StreamEntity
import java.io.InputStream
import java.io.InputStreamReader
import java.util.zip.GZIPInputStream

class CatalogFormatException(msg: String, cause: Throwable? = null) : Exception(msg, cause)

interface CatalogSink {
    suspend fun header(version: Long, generatedAt: String)
    suspend fun countries(rows: List<CountryEntity>)
    suspend fun categories(rows: List<CategoryEntity>)
    suspend fun channels(rows: List<ChannelEntity>)
    suspend fun streams(rows: List<StreamEntity>)
}

class CatalogParser(private val batchSize: Int = 1000) {

    suspend fun parse(input: InputStream, importId: Long, sink: CatalogSink) {
        try {
            JsonReader(InputStreamReader(GZIPInputStream(input), Charsets.UTF_8)).use { r ->
                var version = -1L; var generatedAt = ""
                r.beginObject()
                while (r.hasNext()) {
                    when (r.nextName()) {
                        "version" -> version = r.nextLong()
                        "generatedAt" -> { generatedAt = r.nextString(); if (version >= 0) sink.header(version, generatedAt) }
                        "countries" -> batch(r, { readCountry(r, importId) }, sink::countries)
                        "categories" -> batch(r, { readCategory(r, importId) }, sink::categories)
                        "channels" -> batch(r, { readChannel(r, importId) }, sink::channels)
                        "streams" -> batch(r, { readStream(r, importId) }, sink::streams)
                        else -> r.skipValue()
                    }
                }
                r.endObject()
                if (version < 0) throw CatalogFormatException("missing version")
            }
        } catch (e: CatalogFormatException) { throw e }
        catch (e: Exception) { throw CatalogFormatException("catalog parse failed: ${e.message}", e) }
    }

    private suspend fun <T> batch(r: JsonReader, readOne: () -> T, emit: suspend (List<T>) -> Unit) {
        val buf = ArrayList<T>(batchSize)
        r.beginArray()
        while (r.hasNext()) { buf += readOne(); if (buf.size >= batchSize) { emit(ArrayList(buf)); buf.clear() } }
        r.endArray()
        if (buf.isNotEmpty()) emit(buf)
    }

    private fun JsonReader.nextStringOrNull(): String? = if (peek() == JsonToken.NULL) { nextNull(); null } else nextString()
    private fun JsonReader.nextIntOrNull(): Int? = if (peek() == JsonToken.NULL) { nextNull(); null } else nextInt()
    private fun JsonReader.stringList(): List<String> { val l = ArrayList<String>(); beginArray(); while (hasNext()) l += nextString(); endArray(); return l }

    private fun readCountry(r: JsonReader, importId: Long): CountryEntity {
        var code = ""; var name = ""; var flag = ""
        r.beginObject(); while (r.hasNext()) when (r.nextName()) { "code" -> code = r.nextString(); "name" -> name = r.nextString(); "flag" -> flag = r.nextString(); else -> r.skipValue() }; r.endObject()
        return CountryEntity(code, name, flag, importId)
    }
    private fun readCategory(r: JsonReader, importId: Long): CategoryEntity {
        var id = ""; var name = ""
        r.beginObject(); while (r.hasNext()) when (r.nextName()) { "id" -> id = r.nextString(); "name" -> name = r.nextString(); else -> r.skipValue() }; r.endObject()
        return CategoryEntity(id, name, importId)
    }
    private fun readChannel(r: JsonReader, importId: Long): ChannelEntity {
        var id = ""; var name = ""; var alt = emptyList<String>(); var country: String? = null; var region: String? = null
        var cats = emptyList<String>(); var network: String? = null; var logo: String? = null; var adult = false; var hasUp = false
        r.beginObject()
        while (r.hasNext()) when (r.nextName()) {
            "id" -> id = r.nextString(); "name" -> name = r.nextString(); "altNames" -> alt = r.stringList()
            "country" -> country = r.nextStringOrNull(); "region" -> region = r.nextStringOrNull()
            "categories" -> cats = r.stringList(); "network" -> network = r.nextStringOrNull(); "logo" -> logo = r.nextStringOrNull()
            "adult" -> adult = r.nextBoolean(); "hasUp" -> hasUp = r.nextBoolean(); else -> r.skipValue()
        }
        r.endObject()
        return ChannelEntity(id, name, alt.joinToString("|"), country, region, cats.joinToString("|"), network, logo, adult, hasUp, SOURCE_IPTV, importId)
    }
    private fun readStream(r: JsonReader, importId: Long): StreamEntity {
        var channel = ""; var url = ""; var format = "unknown"; var quality: String? = null; var referrer: String? = null; var ua: String? = null
        var health = "down"; var uptime = 0.0; var responseMs: Int? = null; var score = 0.0
        r.beginObject()
        while (r.hasNext()) when (r.nextName()) {
            "channel" -> channel = r.nextString(); "url" -> url = r.nextString(); "format" -> format = r.nextString()
            "quality" -> quality = r.nextStringOrNull(); "referrer" -> referrer = r.nextStringOrNull(); "userAgent" -> ua = r.nextStringOrNull()
            "health" -> health = r.nextString(); "uptime7d" -> uptime = r.nextDouble(); "responseMs" -> responseMs = r.nextIntOrNull()
            "score" -> score = r.nextDouble(); else -> r.skipValue()
        }
        r.endObject()
        return StreamEntity(channelId = channel, url = url, format = format, quality = quality, referrer = referrer, userAgent = ua,
            health = health, uptime7d = uptime, responseMs = responseMs, score = score, source = SOURCE_IPTV, importId = importId)
    }
}
```

```kotlin
package com.tvapp.data.m3u

data class M3uEntry(val name: String, val url: String, val logo: String?, val group: String?, val tvgId: String?, val userAgent: String?, val referrer: String?)
class M3uParseException(val line: Int, val text: String) : Exception("M3U parse error at line $line: $text")

object M3uParser {
    private val attr = Regex("""([A-Za-z0-9\-]+)="([^"]*)"""")

    fun parse(text: String): List<M3uEntry> {
        val lines = text.split("\n").map { it.trimEnd('\r').trim() }
        if (lines.isEmpty() || !lines[0].startsWith("#EXTM3U")) throw M3uParseException(1, lines.firstOrNull() ?: "")
        val out = ArrayList<M3uEntry>()
        var pending: Triple<String, Map<String, String>, Int>? = null  // name, attrs, line number
        var ua: String? = null; var ref: String? = null
        lines.forEachIndexed { idx, raw ->
            val n = idx + 1
            when {
                raw.isEmpty() -> Unit
                raw.startsWith("#EXTINF") -> {
                    if (pending != null) throw M3uParseException(n, raw)
                    val afterColon = raw.substringAfter(":")
                    val attrs = attr.findAll(afterColon).associate { it.groupValues[1].lowercase() to it.groupValues[2] }
                    val name = afterColon.substringAfterLast(",").trim()
                    pending = Triple(name, attrs, n)
                }
                raw.startsWith("#EXTVLCOPT:http-user-agent=") -> ua = raw.substringAfter("=")
                raw.startsWith("#EXTVLCOPT:http-referrer=") -> ref = raw.substringAfter("=")
                raw.startsWith("#") -> Unit
                else -> {
                    val p = pending ?: throw M3uParseException(n, raw)
                    val (name, attrs, _) = p
                    out += M3uEntry(name.ifEmpty { raw }, raw, attrs["tvg-logo"], attrs["group-title"], attrs["tvg-id"], ua, ref)
                    pending = null; ua = null; ref = null
                }
            }
        }
        pending?.let { throw M3uParseException(it.third, lines[it.third - 1]) }
        return out
    }
}
```

```kotlin
package com.tvapp.playback

data class Candidate(val url: String, val health: String, val catalogScore: Double, val quality: String?, val format: String, val referrer: String?, val userAgent: String?)
data class StatSample(val ttffMs: Int?, val rebuffers: Int, val bitrateKbps: Int?, val playedMs: Long)

object LocalScore {
    const val MIN_SAMPLES = 3
    private fun expectedKbps(q: String?): Int = when (Regex("""(\d{3,4})""").find(q ?: "")?.value?.toIntOrNull() ?: 0) {
        in 1080..9999 -> 5000; in 720..1079 -> 3000; in 576..719 -> 2000; in 480..575 -> 1500; in 1..479 -> 800; else -> 2000 }
    private fun median(xs: List<Double>): Double { val s = xs.sorted(); return if (s.size % 2 == 1) s[s.size / 2] else (s[s.size / 2 - 1] + s[s.size / 2]) / 2 }

    fun compute(samples: List<StatSample>, declaredQuality: String?): Double? {
        if (samples.size < MIN_SAMPLES) return null
        val ttffs = samples.mapNotNull { it.ttffMs?.toDouble() }
        val ttffScore = if (ttffs.isEmpty()) 0.5 else 1 - minOf(median(ttffs), 5000.0) / 5000.0
        val hours = samples.sumOf { it.playedMs } / 3_600_000.0
        val perHour = if (hours <= 0) 0.0 else samples.sumOf { it.rebuffers } / hours
        val rebufferScore = 1 - minOf(perHour, 10.0) / 10.0
        val kbps = samples.mapNotNull { it.bitrateKbps?.toDouble() }
        val qualityScore = if (kbps.isEmpty()) 1.0 else minOf(median(kbps) / expectedKbps(declaredQuality), 1.0)
        return 0.4 * ttffScore + 0.4 * rebufferScore + 0.2 * qualityScore
    }
}

object StreamQueue {
    const val DEMOTION_MS = 3_600_000L
    fun order(candidates: List<Candidate>, demotedUrls: Set<String>, localScores: Map<String, Double>): List<Candidate> =
        candidates.sortedWith(compareBy<Candidate> { if (it.url in demotedUrls) 1 else 0 }
            .thenBy { if (it.health != "up") 1 else 0 }
            .thenByDescending { localScores[it.url] ?: it.catalogScore })
}
```

```kotlin
package com.tvapp.playback

import com.tvapp.core.Clock

class TuneBudget(private val clock: Clock, private val totalMs: Long = 10_000, private val perStreamMs: Long = 4_000) {
    private var startedAt = 0L
    fun start() { startedAt = clock.elapsedMs() }
    fun remainingMs(): Long = (totalMs - (clock.elapsedMs() - startedAt)).coerceAtLeast(0)
    fun cutoffMs(streamsRemainingAfterThis: Int): Long =
        if (streamsRemainingAfterThis > 0) minOf(perStreamMs, remainingMs()) else remainingMs()
    fun exhausted() = remainingMs() <= 0
}
```

```kotlin
package com.tvapp.playback

import com.tvapp.core.Clock

sealed class PlayerEvent { object FirstFrame : PlayerEvent(); data class Error(val message: String) : PlayerEvent(); object Ended : PlayerEvent(); object Rebuffer : PlayerEvent() }
sealed class Notice {
    data class Trying(val index: Int, val total: Int) : Notice(); object Switching : Notice(); object BackToLive : Notice()
    data class NotWorking(val tried: Int) : Notice(); object PoorSignal : Notice()
}
sealed class Decision {
    data class Play(val c: Candidate, val notice: Notice?) : Decision()
    data class Stop(val notice: Notice) : Decision()
    object Continue : Decision()
    data class Failed(val c: Candidate) : Decision()
}

class FailoverEngine(private val clock: Clock, private val budgetFactory: () -> TuneBudget) {
    private var queue: List<Candidate> = emptyList()
    private var manual = false
    private var budget: TuneBudget? = null
    private var current: Candidate? = null
    private var currentStartedAt = 0L
    private var hadFirstFrame = false
    private val tried = LinkedHashSet<String>()
    private val worked = LinkedHashSet<String>()
    val failedThisTune = LinkedHashSet<String>()
    val slowThisTune = LinkedHashSet<String>()
    val playing: Candidate? get() = if (hadFirstFrame) current else null
    val attempting: Candidate? get() = current
    private var active = false

    fun begin(queue: List<Candidate>, manual: Boolean = false): Candidate? {
        this.queue = queue; this.manual = manual; active = true
        tried.clear(); worked.clear(); failedThisTune.clear(); slowThisTune.clear()
        budget = budgetFactory().also { it.start() }
        return startNext(null)?.let { (it as? Decision.Play)?.c }
    }

    fun cancel() { active = false; current = null; hadFirstFrame = false }

    private fun remainingAfterCurrent(): Int = queue.count { it.url !in tried && it.url != current?.url }

    private fun pick(): Candidate? {
        val untried = queue.firstOrNull { it.url !in tried }
        if (untried != null) return untried
        // Everything tried: retry streams that worked before, then anything failed, never the one that just died first.
        val last = current?.url
        return queue.firstOrNull { it.url in worked && it.url != last } ?: queue.firstOrNull { it.url != last } ?: queue.firstOrNull()
    }

    private fun startNext(notice: Notice?): Decision {
        val b = budget ?: return Decision.Continue
        if (b.exhausted()) { active = false; current = null; return Decision.Stop(Notice.NotWorking(tried.size)) }
        val next = pick() ?: run { active = false; return Decision.Stop(Notice.NotWorking(tried.size)) }
        val wasRetry = next.url in tried
        current = next; tried += next.url; hadFirstFrame = false; currentStartedAt = clock.elapsedMs()
        val n = if (notice == null) null else if (wasRetry || notice is Notice.Switching) notice else Notice.Trying(tried.size, queue.size)
        return Decision.Play(next, n)
    }

    fun onEvent(e: PlayerEvent): Decision {
        if (!active) return Decision.Continue
        val c = current ?: return Decision.Continue
        return when (e) {
            PlayerEvent.FirstFrame -> { hadFirstFrame = true; worked += c.url; Decision.Continue }
            PlayerEvent.Rebuffer -> Decision.Continue
            is PlayerEvent.Error, PlayerEvent.Ended -> {
                failedThisTune += c.url
                if (manual) { manual = false; active = false; Decision.Failed(c) }
                else if (hadFirstFrame) startNext(Notice.Switching)
                else startNext(Notice.Trying(0, 0))
            }
        }
    }

    fun onTick(): Decision {
        if (!active) return Decision.Continue
        val c = current ?: return Decision.Continue
        if (hadFirstFrame) return Decision.Continue
        val b = budget ?: return Decision.Continue
        val cutoff = b.cutoffMs(remainingAfterCurrent())
        val elapsed = clock.elapsedMs() - currentStartedAt
        if (b.exhausted()) { active = false; current = null; return Decision.Stop(Notice.NotWorking(tried.size)) }
        if (elapsed < cutoff) return Decision.Continue
        slowThisTune += c.url
        return startNext(Notice.Trying(0, 0))
    }
}
```

Note: the single-stream test expects `Continue` at 4001 ms because `cutoffMs(0)` is the full remaining budget; the implementation above satisfies that since `remainingAfterCurrent()` is 0 for a single stream.

```kotlin
                if (playbackState == Player.STATE_ENDED) handle(PlayerEvent.Ended)
                if (playbackState == Player.STATE_BUFFERING && _state.value.playing != null) { measurement.rebuffer(); handle(PlayerEvent.Rebuffer) }
            }
            override fun onVideoSizeChanged(videoSize: VideoSize) { _state.update { it.copy(resolution = "${videoSize.height}p") } }
        })
        player.addAnalyticsListener(object : AnalyticsListener {
            override fun onDownstreamFormatChanged(eventTime: AnalyticsListener.EventTime, mediaLoadData: androidx.media3.exoplayer.source.MediaLoadData) {
                val f: Format = mediaLoadData.trackFormat ?: return
                if (f.bitrate > 0) { measurement.bitrate(f.bitrate / 1000); _state.update { it.copy(bitrateKbps = f.bitrate / 1000) } }
            }
        })
        scope.launch { while (true) { delay(1000); _state.update { it.copy(bufferMs = player.totalBufferedDuration) } } }
    }

    fun tune(channelId: String, manual: Candidate? = null) {
        scope.launch {
            cancelInternal()
            val prev = _state.value.channelId
            if (prev != null && prev != channelId) previousChannel = prev
            _state.update { PlayerState(channelId = channelId) }
            val ids = importer.activeImportIds()
            val streams = db.catalog().streamsForChannel(channelId, ids)
            val candidates = streams.map { Candidate(it.url, it.health, it.score, it.quality, it.format, it.referrer, it.userAgent) }
            if (candidates.isEmpty()) { _state.update { it.copy(notice = Notice.NotWorking(0)) }; return@launch }
            val demoted = db.local().failedUrlsSince(clock.elapsedMs() - StreamQueue.DEMOTION_MS).toSet()
            val local = measurement.localScores(candidates.map { it.url }) { u -> candidates.first { it.url == u }.quality }
            val ordered = if (manual != null) listOf(manual) + StreamQueue.order(candidates.filter { it.url != manual.url }, demoted, local)
                          else StreamQueue.order(candidates, demoted, local)
            if (manual != null) db.local().clearFailures(manual.url)
            val first = engine.begin(ordered, manual = manual != null) ?: return@launch
            val tuneStart = clock.elapsedMs()
            play(first, if (ordered.size > 1) Notice.Trying(1, ordered.size) else null)
            tickJob = scope.launch { while (true) { delay(250); apply(engine.onTick()) } }
            db.local().upsertRecent(RecentEntity(channelId, System.currentTimeMillis()))
            _state.update { it.copy(tuneMs = null) }
            tuneStartedAt = tuneStart
        }
    }
    private var tuneStartedAt = 0L

    private fun play(c: Candidate, notice: Notice?) {
        measurement.start(c.url)
        _state.update { it.copy(attempting = c, playing = null, notice = notice, resolution = null, bitrateKbps = null) }
        val factory = PlayerFactory.mediaSourceFactory(appContext, http, c)
        val item = PlayerFactory.mediaItem(c)
        player.setMediaSource(factory.createMediaSource(item))
        player.prepare(); player.playWhenReady = true
    }

    private fun handle(e: PlayerEvent) { scope.launch { apply(engine.onEvent(e), e) } }

    private suspend fun apply(d: Decision, cause: PlayerEvent? = null) {
        when (d) {
            Decision.Continue -> if (cause == PlayerEvent.FirstFrame) onFirstFrame()
            is Decision.Play -> { recordFailureIfReal(cause); play(d.c, d.notice) }
            is Decision.Failed -> { recordFailureIfReal(cause); _state.update { it.copy(notice = Notice.NotWorking(1), attempting = null) } }
            is Decision.Stop -> {
                recordFailureIfReal(cause); tickJob?.cancel(); player.stop()
                val ch = _state.value.channelId
                if (ch != null && network.isValidated() && !outageGuard()) db.local().upsertChannelStatus(brokenHere.afterFailure(db.local().channelStatus(ch), ch))
                consecutiveChannelFailures++; lastChannelFailureAt = clock.elapsedMs()
                _state.update { it.copy(notice = d.notice, attempting = null, playing = null) }
            }
        }
    }

    private suspend fun onFirstFrame() {
        measurement.firstFrame()
        val c = engine.playing ?: return
        val ch = _state.value.channelId
        consecutiveChannelFailures = 0
        if (ch != null) db.local().deleteChannelStatus(ch)
        _state.update { it.copy(playing = c, attempting = null, notice = null, tuneMs = clock.elapsedMs() - tuneStartedAt) }
        scope.launch { delay(3000); _state.update { if (it.playing == c) it.copy(notice = null) else it } }
    }

    private fun outageGuard(): Boolean = consecutiveChannelFailures >= 3 && clock.elapsedMs() - lastChannelFailureAt < 60_000

    private suspend fun recordFailureIfReal(cause: PlayerEvent?) {
        if (cause !is PlayerEvent.Error && cause != PlayerEvent.Ended) return
        val url = _state.value.attempting?.url ?: _state.value.playing?.url ?: return
        if (!network.isValidated() || outageGuard()) return
        db.local().insertFailure(StreamFailureEntity(streamUrl = url, failedElapsedMs = clock.elapsedMs()))
    }

    fun cancel() { scope.launch { cancelInternal() } }
    private suspend fun cancelInternal() { tickJob?.cancel(); engine.cancel(); measurement.flush(); player.stop() }

    fun pause() { player.playWhenReady = false; _state.update { it.copy(paused = true) } }
    fun play() {
        if (_state.value.paused) { player.seekToDefaultPosition(); player.playWhenReady = true
            _state.update { it.copy(paused = false, notice = Notice.BackToLive) }
            scope.launch { delay(2000); _state.update { if (it.notice == Notice.BackToLive) it.copy(notice = null) else it } } }
    }
    fun previous() { previousChannel?.let { tune(it) } }
    fun retuneToLive() { _state.value.channelId?.let { tune(it) } }
    fun release() { scope.launch { measurement.flush() }; player.release() }
}
```

```kotlin
import android.content.Context
import androidx.work.Constraints
import androidx.work.ExistingPeriodicWorkPolicy

import okhttp3.OkHttpClient
import okhttp3.Request
import java.io.InputStream
import java.util.concurrent.TimeUnit

interface ImportSink {
    suspend fun activeVersion(): Long?
    suspend fun importStream(input: InputStream): ImportResult
}

data class LatestCheck(val remoteVersion: Long?, val localVersion: Long?, val updateAvailable: Boolean)

class CatalogSync(private val http: OkHttpClient, private val sink: ImportSink, private val baseUrl: suspend () -> String) {
    suspend fun checkLatest(): LatestCheck = withContext(Dispatchers.IO) {
        val local = sink.activeVersion()
        val remote = try {
            http.newCall(Request.Builder().url("${baseUrl()}/latest.json").header("Cache-Control", "no-cache").build()).execute().use { r ->
                if (!r.isSuccessful) null else JsonParser.parseString(r.body!!.string()).asJsonObject["version"].asLong
            }
        } catch (e: Exception) { null }
        LatestCheck(remote, local, remote != null && remote != local)
    }

    suspend fun download(onProgress: (Long, Long) -> Unit = { _, _ -> }): ImportResult = withContext(Dispatchers.IO) {
        http.newCall(Request.Builder().url("${baseUrl()}/catalog.json.gz").build()).execute().use { r ->
            if (!r.isSuccessful) throw CatalogFormatException("catalog download HTTP ${r.code}")
            val total = r.body!!.contentLength()
            val counting = object : InputStream() {
                val inner = r.body!!.byteStream(); var read = 0L
                override fun read(): Int = inner.read().also { if (it >= 0) { read++; onProgress(read, total) } }
                override fun read(b: ByteArray, off: Int, len: Int): Int = inner.read(b, off, len).also { if (it > 0) { read += it; onProgress(read, total) } }
                override fun close() = inner.close()
            }
            sink.importStream(counting)
        }
    }

    companion object {
        const val PERIODIC = "catalog-sync-periodic"; const val IDLE = "catalog-sync-idle"
        fun schedulePeriodic(context: Context) {
            val constraints = Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).setRequiresDeviceIdle(true).build()
            WorkManager.getInstance(context).enqueueUniquePeriodicWork(PERIODIC, ExistingPeriodicWorkPolicy.KEEP,
                PeriodicWorkRequestBuilder<CatalogSyncWorker>(24, TimeUnit.HOURS).setConstraints(constraints).build())
        }
        fun runWhenIdle(context: Context) {
            val constraints = Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).build()
            WorkManager.getInstance(context).enqueueUniqueWork(IDLE, ExistingWorkPolicy.KEEP,
                OneTimeWorkRequestBuilder<CatalogSyncWorker>().setConstraints(constraints).build())
        }
    }
}

class ImporterSink(private val importer: CatalogImporter, private val db: com.tvapp.data.db.AppDatabase) : ImportSink {
    override suspend fun activeVersion(): Long? = db.local().setting(CatalogImporter.KEY_VERSION)?.toLongOrNull()
    override suspend fun importStream(input: InputStream): ImportResult = importer.import(input)
}
```

```kotlin
package com.tvapp.playback

import android.net.Uri
import androidx.media3.common.MediaItem
import androidx.media3.datasource.DataSource
import com.tvapp.core.Clock
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.Job
import kotlinx.coroutines.delay
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext
import okhttp3.OkHttpClient
import okhttp3.Request

interface PreloadHandle { fun add(item: MediaItem, factory: DataSource.Factory); fun clear() }

class Preloader(
    private val http: OkHttpClient, private val scope: CoroutineScope, private val clock: Clock,
    private val handleFactory: () -> PreloadHandle?, private val debounceMs: Long = 300,
) {
    var preloadCount: Int = 1
    private var focusJob: Job? = null
    private var neighborJob: Job? = null
    private val preloaded = LinkedHashSet<String>()

    fun focus(candidate: Candidate?, playingHost: String?) {
        focusJob?.cancel()
        if (candidate == null) return
        focusJob = scope.launch { delay(debounceMs); warm(candidate, playingHost, preload = preloadCount > 0) }
    }

    fun neighbors(prev: Candidate?, next: Candidate?, playingHost: String?) {
        neighborJob?.cancel()
        neighborJob = scope.launch {
            delay(debounceMs)
            handleFactory()?.clear(); preloaded.clear()
            if (preloadCount >= 1 && next != null) warm(next, playingHost, preload = true)
            if (preloadCount >= 2 && prev != null) warm(prev, playingHost, preload = true)
        }
    }

    fun take(url: String): Boolean = preloaded.remove(url)

    private suspend fun warm(c: Candidate, playingHost: String?, preload: Boolean) {
        prefetch(c)
        val host = runCatching { Uri.parse(c.url).host }.getOrNull()
        if (preload && host != null && host != playingHost) {
            handleFactory()?.add(PlayerFactory.mediaItem(c), PlayerFactory.dataSourceFactory(http, c))
            preloaded += c.url
        }
    }

    private suspend fun prefetch(c: Candidate) = withContext(Dispatchers.IO) {
        runCatching {
            val b = Request.Builder().url(c.url)
            c.referrer?.let { b.header("Referer", it) }; c.userAgent?.let { b.header("User-Agent", it) }
            http.newCall(b.build()).execute().use { it.body?.bytes() }
        }
    }
}
```

```kotlin
package com.tvapp.ui.state

import android.view.KeyEvent

enum class Overlay { NONE, CHANNELS, BROWSE, SEARCH, FAVORITES, SETTINGS, ADVANCED, DIAGNOSTICS, CONTEXT_MENU, SOURCES, STRIP }

sealed class Action {
    object SurfUp : Action(); object SurfDown : Action(); object ShowBanner : Action(); object ContextMenu : Action()
    object Previous : Action(); object Strip : Action(); object OpenChannels : Action(); object PlayPause : Action()
    data class Digit(val n: Int) : Action(); object Back : Action(); object None : Action()
}

object KeyRouter {
    fun route(key: Int, longPress: Boolean, doubleTap: Boolean, top: Overlay): Action {
        // Keys that work everywhere.
        when (key) {
            KeyEvent.KEYCODE_BACK -> return Action.Back
            KeyEvent.KEYCODE_MEDIA_PLAY_PAUSE, KeyEvent.KEYCODE_MEDIA_PLAY, KeyEvent.KEYCODE_MEDIA_PAUSE -> return Action.PlayPause
            KeyEvent.KEYCODE_LAST_CHANNEL -> return Action.Previous
            KeyEvent.KEYCODE_GUIDE -> return Action.OpenChannels
        }
        if (top != Overlay.NONE) return Action.None
        return when (key) {
            KeyEvent.KEYCODE_DPAD_UP, KeyEvent.KEYCODE_CHANNEL_UP -> Action.SurfUp
            KeyEvent.KEYCODE_DPAD_DOWN, KeyEvent.KEYCODE_CHANNEL_DOWN -> Action.SurfDown
            KeyEvent.KEYCODE_DPAD_CENTER, KeyEvent.KEYCODE_ENTER, KeyEvent.KEYCODE_INFO ->
                if (longPress) Action.ContextMenu else if (doubleTap) Action.Previous else Action.ShowBanner
            KeyEvent.KEYCODE_DPAD_LEFT, KeyEvent.KEYCODE_DPAD_RIGHT -> Action.Strip
            in KeyEvent.KEYCODE_0..KeyEvent.KEYCODE_9 -> Action.Digit(key - KeyEvent.KEYCODE_0)
            else -> Action.None
        }
    }
}
```

```kotlin
// in MainActivity
override fun dispatchKeyEvent(event: KeyEvent): Boolean {
    val vm = viewModel
    if (event.action == KeyEvent.ACTION_DOWN && event.repeatCount > 0 && event.keyCode == KeyEvent.KEYCODE_DPAD_CENTER) {
        if (!centerLongHandled) { centerLongHandled = true; return applyAction(KeyRouter.route(event.keyCode, longPress = true, doubleTap = false, vm.top)) }
        return true
    }
    if (event.action != KeyEvent.ACTION_UP) return super.dispatchKeyEvent(event)
    if (event.keyCode == KeyEvent.KEYCODE_DPAD_CENTER) {
        if (centerLongHandled) { centerLongHandled = false; return true }
        val now = SystemClock.uptimeMillis(); val dbl = now - lastCenterUp < 350; lastCenterUp = if (dbl) 0 else now
        val action = KeyRouter.route(event.keyCode, false, dbl, vm.top)
        return if (action == Action.None) super.dispatchKeyEvent(event) else applyAction(action)
    }
    val action = KeyRouter.route(event.keyCode, false, false, vm.top)
    return if (action == Action.None) super.dispatchKeyEvent(event) else applyAction(action)
}

private fun applyAction(a: Action): Boolean {
    val vm = viewModel
    when (a) {
        Action.SurfUp -> vm.surf(+1); Action.SurfDown -> vm.surf(-1)
        Action.ShowBanner -> vm.showBanner(); Action.ContextMenu -> vm.push(Overlay.CONTEXT_MENU)
        Action.Previous -> vm.previous(); Action.Strip -> vm.push(Overlay.STRIP)
        Action.OpenChannels -> { vm.closeAll(); vm.push(Overlay.CHANNELS) }
        Action.PlayPause -> vm.playPause(); is Action.Digit -> vm.favoriteByNumber(a.n)
        Action.Back -> { if (!vm.pop()) { if (vm.armExit()) finish() } }
        Action.None -> return false
    }
    return true
}
```

```kotlin
package com.tvapp.playback

import com.tvapp.core.Clock

class PoorSignal(private val clock: Clock, private val declaredQuality: () -> String?) {
    private val rebuffers = ArrayDeque<Long>()
    private var lowSince: Long? = null
    private val lastPrompt = HashMap<String, Long>()

    fun reset() { rebuffers.clear(); lowSince = null }
    fun onRebuffer() { val now = clock.elapsedMs(); rebuffers.addLast(now); while (rebuffers.isNotEmpty() && now - rebuffers.first() > 60_000) rebuffers.removeFirst() }
    fun onResolution(height: Int) {
        val declared = Regex("""(\d{3,4})""").find(declaredQuality() ?: "")?.value?.toIntOrNull()
        if (declared == null) { lowSince = null; return }
        lowSince = if (height < declared * 0.6) (lowSince ?: clock.elapsedMs()) else null
    }
    fun shouldPrompt(channelId: String): Boolean {
        val now = clock.elapsedMs()
        lastPrompt[channelId]?.let { if (now - it <= 10 * 60_000) return false }
        val recent = rebuffers.count { now - it <= 60_000 }
        val low = lowSince?.let { now - it > 30_000 } ?: false
        if (recent >= 3 || low) { lastPrompt[channelId] = now; rebuffers.clear(); lowSince = null; return true }
        return false
    }
}
```
